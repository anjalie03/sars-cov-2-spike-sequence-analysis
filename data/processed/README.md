# data/processed

Processed files derived from the raw SARS-CoV-2 spike sequences. These are generated by the notebook `spike_protein_variant_analysis.ipynb`.

## Files

| File | Description |
|------|-------------|
| `spike_aligned.fasta` | Multiple sequence alignment of 10 spike protein sequences (1276 alignment columns, amino acids) |
| `spike_aligned.fasta.treefile` | Maximum-likelihood tree from IQ-TREE 2.0.7 |
| `spike_aligned.fasta.contree` | Consensus tree with ultrafast bootstrap support (1000 replicates) |
| `spike_aligned.fasta.iqtree` | IQ-TREE report: best-fit model, log-likelihood, tree statistics |
| `spike_aligned.fasta.log` | IQ-TREE run log |
| `spike_aligned.fasta.mldist` | Maximum-likelihood pairwise distance matrix |
| `spike_aligned.fasta.bionj` | Initial BIONJ tree used to start the search |
| `spike_aligned.fasta.splits.nex` | Bootstrap splits in Nexus format |
| `spike_aligned.fasta.ckp.gz` | IQ-TREE checkpoint file |
| `spike_aligned.fasta.model.gz` | ModelFinder model test results |

## How these were made

1. Spike protein sequences were aligned (tool: ADD, e.g. MAFFT) to produce `spike_aligned.fasta`.
2. The alignment was analyzed with IQ-TREE 2.0.7 using ModelFinder and 1000 ultrafast bootstrap replicates.

## Notes

- Alignment: 10 sequences, 1276 sites, 96.9% constant sites, 37 parsimony-informative sites.
- Files here can be regenerated by running the notebook from the top.
