# Results/Tables

Result tables generated by the notebook `spike_protein_variant_analysis.ipynb` from the SARS-CoV-2 spike sequence analysis.

## Files

| File | Description |
|------|-------------|
| `mutations.csv` | Mutations called for each sequence relative to the reference spike (ADD: describe columns, e.g. position, reference aa, variant aa) |
| `pairwise_vs_reference.csv` | Pairwise comparison of each sequence against the reference (ADD: e.g. identity and number of differences) |
| `sequence_stats.csv` | Basic statistics per sequence (ADD: e.g. length, composition) |

## How these were made

- Sequences come from the alignment in `data/processed/spike_aligned.fasta`.
- Tables were created with Biopython and pandas and saved with `df.to_csv(...)`.
- Re-running the notebook from the top regenerates all tables.

## Notes

- Reference sequence: ADD (e.g. Wuhan-Hu-1, UniProt P0DTC2, 1273 aa).
- Mutation positions are numbered ADD (relative to the reference spike, or alignment columns).
