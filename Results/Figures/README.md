# Results/Figures

Figures generated by the notebook `spike_protein_variant_analysis.ipynb` from the SARS-CoV-2 spike sequence analysis (Wuhan reference plus 3 Alpha, 3 Delta, and 3 Omicron sequences).

## Files

| File | Description |
|------|-------------|
| `spike_tree.png` | Maximum-likelihood tree drawn from the IQ-TREE output (`spike_aligned.fasta.treefile`) |
| `spike_tree_bootstrap.png` | Tree with ultrafast bootstrap support values (from `spike_aligned.fasta.contree`) |
| `ml_tree.png` | Maximum-likelihood tree figure (ADD: check how it differs from `spike_tree.png`) |
| `nj_tree.png` | Neighbor-joining tree for comparison with the maximum-likelihood tree |
| `mutation_counts.png` | Number of mutations per sequence relative to the reference |
| `mutation_map.png` | Positions of mutations along the spike sequence |
| `lengths.png` | Sequence lengths per sample compared with the reference (1273 aa) |
| `aa_composition.png` | Amino acid composition of the sequences |

## How these were made

- Trees were drawn with Biopython (`Bio.Phylo`) and matplotlib from the IQ-TREE output in `data/processed/`.
- Plots were saved with `plt.savefig(...)`.
- Re-running the notebook from the top regenerates all figures.

## Notes

- Bootstrap values of 95 or higher are generally considered well supported for UFBoot.
- The alignment has only 37 parsimony-informative sites, so some branches may have low support.
