# Results/Figures

Figures generated by the notebook `spike_protein_variant_analysis.ipynb` from the SARS-CoV-2 spike sequence analysis.

## Files

| File | Description |
|------|-------------|
| `spike_tree.png` | Maximum-likelihood phylogenetic tree of the spike sequences (IQ-TREE, from `spike_aligned.fasta.treefile`) |
| `spike_tree_bootstrap.png` | Same tree with ultrafast bootstrap support values (from `spike_aligned.fasta.contree`) |
| ADD | Mutation frequency plot |
| ADD | Mutation heatmap across variants |

## How these were made

- Trees were drawn with Biopython (`Bio.Phylo`) and matplotlib from the IQ-TREE output in `data/processed/`.
- Plots were saved at 300 dpi with `plt.savefig(...)`.
- Re-running the notebook from the top regenerates all figures.

## Notes

- Bootstrap values of 95 or higher are generally considered well supported for UFBoot.
- The alignment has only 37 parsimony-informative sites, so some branches may have low support.
